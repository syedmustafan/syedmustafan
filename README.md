- 📄 Document RAG pipeline: chunk to embed to retrieve via ChromaDB
- 🔍 LangSmith agent observability and tracing
- 💬 React/Vite frontend with streaming chat UX

- ☁️ Containerized, deployed via CI/CD to GCP and Vercel
